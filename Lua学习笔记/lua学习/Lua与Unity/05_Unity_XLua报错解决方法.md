## 问题原因

XLua 在 Unity 中报错通常由以下原因导致：

- **.NET 兼容性问题**：.NET Standard 2.0 对某些高级特性支持不完整
- **代码缓存冲突**：XLua 自动生成的代码与实际代码不同步
- **VS 解决方案问题**：Visual Studio 解决方案文件缓存了旧的类型信息
- **编译顺序问题**：Unity 脚本编译顺序导致 XLua 生成代码时找不到类型

## 完整操作步骤

### 第一步：修改 Unity API 兼容级别（核心）

1. 打开 Unity 编辑器
2. 顶部菜单点击 **Edit** → **Project Settings** → **Player**
3. 在右侧面板找到 **Other Settings** → **Configuration** 分组
4. 找到 **Api Compatibility Level**
5. 将默认的 **.NET Standard 2.0** 修改为 **.NET 4.x**（或 .NET Framework）

> 注意：新版 Unity 可能显示为 .NET 4.x 或 .NET Framework，请选择其中一个

6. 等待 Unity 右下角转圈完成（自动重新编译）

### 第二步：清理 XLua 生成代码

1. 回到 Unity 顶部菜单
2. 找到 **XLua** 菜单
3. 点击 **Clear Generate Code**

> 作用：删除旧的、错误的 XLua 自动生成代码，避免缓存冲突

### 第三步：清理 Visual Studio 解决方案

1. 在 Unity 中，右键任意脚本 → **Open C# Project** 打开 VS
2. 在 VS 顶部菜单：
   - **生成** → **清理解决方案**
3. 清理完成后：
   - **生成** → **生成解决方案**
4. 关闭 VS，回到 Unity 等待编译完成

### 第四步：重启 Unity（必做）

1. 完全关闭 Unity 编辑器
2. 重新启动 Unity
3. 等待项目完全加载和编译

## 常见报错类型

### 错误类型一：找不到类型

```
error CS0246: The type or namespace name 'XLua' could not be found
```

**解决方法**：执行第一步和第二步

### 错误类型二：方法调用失败

```
XLua.LuaException: method not found: xxx
```

**解决方法**：执行第二步和第三步

### 错误类型三：生成代码异常

```
Assets/XLua/Src/Editor/Generator.cs(123,45): error CS1234: ...
```

**解决方法**：执行第一步和第二步

### 错误类型四：泛型相关错误

```
The type 'xxx' has no supported conversion to CS-to-Lua
```

**解决方法**：执行第一步，重启 Unity

## 注意事项

### 重要提醒

1. **必须重启 Unity**：清理后不重启会导致配置不生效
2. **备份项目**：操作前建议备份项目或使用版本控制
3. **按顺序执行**：严格按照四步顺序操作，不要跳过
4. **等待编译完成**：每一步都要等待 Unity 完成编译再进行下一步

### 配置建议

| 设置项 | 推荐值 | 说明 |
|--------|--------|------|
| Api Compatibility Level | .NET 4.x | 支持更多 .NET 特性 |
| Managed Stripping Level | Low | 减少代码裁剪问题 |
| Allow 'unsafe' Blocks | 按需开启 | 使用 unsafe 代码时需要 |

### XLua 目录结构

```
Assets/
├── XLua/
│   ├── Src/
│   │   ├── Editor/          # 编辑器脚本
│   │   └── Gen/             # 自动生成代码目录
│   └── Examples/
└── Scripts/
    └── Lua/                 # 你的 Lua 脚本目录
```

## 验证方法

完成以上步骤后，可以通过以下方式验证：

### 方法一：运行示例场景

1. 打开 Unity 菜单 **XLua** → **Examples**
2. 找到并运行示例场景
3. 检查控制台是否有报错

### 方法二：测试自定义功能

1. 在 Lua 脚本中调用 C# 方法
2. 检查是否能正常调用
3. 验证返回值是否正确

### 方法三：检查生成代码

1. 查看目录 `Assets/XLua/Src/Gen/`
2. 确认生成代码文件是否存在
3. 检查是否包含你定义的类型

## 总结

| 步骤 | 操作 | 作用 |
|------|------|------|
| 第一步 | Api Compatibility Level 改为 .NET 4.x | 解决兼容性问题 |
| 第二步 | XLua → Clear Generate Code | 清理旧代码缓存 |
| 第三步 | VS 清理 + 重新生成解决方案 | 解决VS缓存问题 |
| 第四步 | 完全重启 Unity | 让配置生效 |

按照这个流程操作，**99% 的 XLua 兼容、代码生成类报错**都能直接解决！

## 附加技巧

### 技巧一：定期清理

建议每周执行一次 Clear Generate Code，保持代码新鲜

### 技巧二：使用版本控制

将 `Assets/XLua/Src/Gen/` 目录添加到 .gitignore，避免提交生成代码

### 技巧三：检查第三方库

如果问题仍然存在，检查项目中其他第三方库是否与 XLua 冲突
